# Creature Clash Lab

A kid-friendly prototype for funny, educational creature matchups inspired by "who would win?" style debates.

## Run locally

```bash
node server.js
```

Then open http://localhost:4174.

## Deploy later

This is a static app: `index.html`, `styles.css`, and `app.js`. It can be deployed to Vercel, Netlify, Cloudflare Pages, GitHub Pages, or any basic web host.

## Prototype goals

- Pick two creatures.
- Choose an arena.
- Make a guess.
- Run a comical battle simulation.
- Show why the winner had the edge.
- Teach facts without making the battle feel like homework.
